## 定义

把事后剔除失败样本后算出的比例误认为总体成功率。剔除决定晚于观察结果，且剔除理由与结果相关，剩余样本不再代表原总体。

必须先选定一种估计量。二值成功率以全部发起单元为分母，未完成按未成功计，删失时间只用于另报中位数或分位数。时间到成功则以各事件时刻的风险集为分母，只给曲线与分位数，不给单一比值。两类估计量不得混用。

## 示例

30 次发起中 8 次超时。报告把这 8 次列为“未完成”并从统计中移除，剩余 22 次中 20 次成功，称成功率 91%。二值口径下总体为 20/30，未完成按未成功计。若研究问题是时间到成功，则应给风险集与曲线，而不是 91%。

## 识别方法

- 索取剔除规则的登记时间，判断规则先于还是晚于结果。
- 统计被剔除样本的数量、原因码与结果分布；剔除集中在失败侧提示选择性剔除。
- 用全样本重算成功率，与剔除后数值并列。
- 检查未完成观测按哪种估计量处理，是否在报告中被静默移除。
- 检查同一张表是否混用二值比例与生存分析估计量。
- 最小证伪：要求每个被剔除样本的原始日志与独立判据；判据无法脱离结果复现即为事后剔除。

## 预防与验收要求

- 必须在实验开始前登记纳入与排除规则，写明超时、环境故障、脚本错误的判据与证据要求。
- 排除必须由与结果无关的判据触发，并在运行时写入原因码；不得在分析阶段补记。
- 必须在报告中声明主估计量为二值成功率还是时间到成功；同一指标不得同时用比值与曲线表述。
- 二值口径下，全部发起单元计入分母，未完成按未成功计；删失时间仅作附报。
- 时间到事件口径下，必须给出风险集定义与曲线，不设单一 `rate_all`。
- 必须同时报告全样本结果与剔除后结果。剔除比例上限由项目验收方案定义。

## 验收证据与量化字段

- 实验前登记的排除规则文件及其时间戳。
- 逐次记录：结果、是否剔除、原因码、判据引用。
- 全样本与剔除后两套分子、分母与比值。
- 被剔除样本的原始日志摘录。

| 字段 | 含义 | 单位/取值 |
|---|---|---|
| `n_started` | 发起的观测总数 | 个 |
| `n_completed` | 产生明确成功或失败判定的观测数 | 个 |
| `n_excluded` | 被移出分析的观测数 | 个 |
| `exclusion_rule_id` | 触发剔除的规则标识 | 字符串 |
| `exclusion_rule_registered_at` | 规则登记时间相对实验开始的位置 | 枚举：实验前/实验中/实验后 |
| `excluded_failure_fraction` | 被剔除样本中失败所占比例 | 比值 |
| `estimator_type` | 报告所采用的主估计量 | 枚举：binary / time_to_event |
| `rate_all` | 二值口径：成功数 ÷ 全部发起数，未完成按未成功计 | 比值 |
| `rate_after_exclusion` | 剔除后口径的成功率 | 比值 |
| `at_risk_definition` | 时间到事件口径的风险集定义；二值口径为空 | 字符串 |
| `censored_runtime_median` | 未完成观测已运行时间的中位数，仅作附报 | 秒 |

## 边界与关联

- 规则事先登记且判据可由独立日志证实时，剔除合法，但仍须报告全样本结果。
- 删失不是剔除：删失保留风险时间，剔除丢弃整条观测。
- 清理或恢复操作掩盖副作用归 VXP-037；原始记录不足使剔除无法审计归 VXP-040。
- 本条目不判断分母定义是否漂移，见 VXP-025。
- 无子条目。
