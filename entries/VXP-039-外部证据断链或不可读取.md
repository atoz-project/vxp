## 定义

把“结论里引用了证据”误认为“验收时能取得同一份材料”。外部证据指结论之外、由他方或他处保管的材料。引用失效包括三种情况：定位不到具体对象、访问不到、无法证明是同一份。

## 示例

一份报告引用代码托管链接与工单编号，验收时链接返回 404，工单已关闭。另一份只写“见附件”，附件没有进入受控存储。两处结论都写“证据已提供”。证据实际支持的结论是“提交时曾存在若干地址”。

## 识别方法

- 从与证据所有者无关的账号逐条解析引用，记录状态码、最终对象与访问时间。
- 检查引用是否落到不可变对象，而非入口页或默认分支。
- 检查是否保存带采集时间与哈希的快照。
- 检查访问是否依赖个人账号、本地路径或即时通讯记录。
- 检查证据保留期是否覆盖验收与争议处理期。

## 预防与验收要求

- 每条结论绑定证据索引项：定位符、版本或哈希、保管人、访问方法、最后校验时间。
- 证据存放在受控位置，具备保留策略与不可变能力。
- 在线页面必须保存快照，不得只引用会滚动更新的页面。
- 访问路径由非所有者按文档验证。审批提前完成，并记录范围与有效期。
- 解密材料与加密证据分开托管，见 VXP-039.002。
- 保留期由项目定义，本条目不给出数值。

## 验收证据与量化字段

最小证据：

- 证据索引：条目 ID、类型、定位符、版本或哈希、采集时间、保管人、访问方法、最后校验时间与校验人。
- 在线材料的快照，含采集时间、工具与内容哈希。
- 非所有者访问测试记录。
- 加密证据的托管记录，不含密钥值。

| 字段 | 含义 | 单位/取值 |
|---|---|---|
| `resolvable_ratio` | 评审时可从引用定位到具体对象的条目占比 | 比例 |
| `exact_locator_ratio` | 引用指向不可变对象而非入口页的条目占比 | 比例 |
| `hash_verified_ratio` | 重算哈希与记录一致的条目占比 | 比例 |
| `access_without_owner_ratio` | 无需所有者到场即可取得的条目占比 | 比例 |
| `link_type` | 引用类型 | `immutable_id` / `versioned_url` / `mutable_url` / `local_path` / `chat` |
| `retention_until` | 承诺保留到的日期 | 日期 |

## 边界与关联

- 受访问控制的证据不属于引用失效：有文档化授权路径、可执行审批与明确保管人时仍可取得。
- 私有材料可在受控评审室查阅，但必须记录查阅人、时间与范围。
- 引用修复必须保留旧引用与新引用的映射，不得静默替换。
- 本条目不判断内容是否充分（VXP-040）、来源是否独立（VXP-038）、终局是否被观测（VXP-043）。

子条目：

- VXP-039.001 可变定位符未绑定证据对象：检查引用能否解析到具体对象。
- VXP-039.002 加密保存误作授权方随时可取：检查密钥托管与保管人缺席时的取得路径。
- VXP-039.003 个人可访问误作评审方可取得：检查访问路径是否文档化并由非所有者走通。

## 参考来源

1. CCSDS，CCSDS 650.0-M-2《Reference Model for an Open Archival Information System (OAIS)》，https://public.ccsds.org/Pubs/650x0m2.pdf，查询日期 2026-11-20。该标准用固定性信息确保内容对象未被未记录方式修改，可支撑以哈希和固定性信息绑定证据版本的要求。
