## 定义

把一次“又跑通了”误认为达到了约定的复现等级。把逐字节一致误认为唯一合格标准，属于另一类误读。

复现等级由执行者与制品来源共同决定：同队同设置为 repeatability，异队同设置为 reproducibility，异队使用完全独立制品为 replicability。容差是允许的结果差异范围，前提是差异不改变主要主张。等级与容差属于项目验收约定；ACM 徽章是学术制品评审标签，不能直接折算为漏洞验收分数。

## 示例

交付方在作者机器上连续运行三次，输出一致，报告写“可复现”。验收要求异队使用作者制品重跑，该步骤没有执行。错误结论：已达最高复现等级。证据支持的结论：达到同队重复，未达到异队复现。

另一项目要求输出逐字节一致，因时间戳不同判为失败；实际成功谓词与主要主张均未改变。错误结论：复现失败。证据支持的结论：差异在合理容差内，结论成立。

## 识别方法

- 报告是否声明复现等级，并按执行者与制品来源判定，而非按运行次数。
- 复跑者是否独立于作者团队；所用制品来自作者、第三方还是完全独立实现。
- 容差是否在任何运行前写入验收合同，并绑定到具体哪条成功谓词。
- 差异是否落在容差内，是否改变主要主张。
- 是否把 ACM 徽章、会议标签或类似评审结果直接当作验收分数。

## 预防与验收要求

- 验收合同预先选定等级，写明执行者、制品来源与最低证据。
- 容差与成功谓词同时声明；超出容差或改变主要主张判为不通过。
- 等级按证据判定：同队运行不升级为异队复现，作者制品不升级为独立复现。
- ACM 徽章可作方法论参考，不得替代本项目的证据审查。
- 未达约定等级但结果部分一致时，记为“条件复现”并列出差异项。
- 等级命名与容差数值由项目约定，本条目不设统一阈值。

## 验收证据与量化字段

最小证据：等级声明与判定依据；复跑者身份与制品来源；预先声明的容差；结果差异清单；主要主张是否保持的判断记录。

| 字段 | 含义 | 单位/取值 |
|---|---|---|
| `reproduction_level` | 按执行者与制品来源判定的复现等级 | `repeatability` / `reproducibility` / `replicability` |
| `artifact_origin` | 复跑所用制品的来源 | `author` / `third_party` / `independent` |
| `tolerance_declared` | 容差是否在运行前声明 | `yes` / `no` |
| `tolerance_exceeded` | 实测差异是否超出声明容差 | `yes` / `no` / `not_applicable` |
| `primary_claim_preserved` | 差异是否保持主要主张不变 | `yes` / `partial` / `no` |

## 边界与关联

- 与 VXP-038 的分工：038 检查复跑证据由谁采集与保存；本条目检查复现等级口径与容差判定。
- 独立复跑只满足 reproducibility 的执行者条件，不自动满足制品独立或容差要求。
- 与 VXP-025 的分工：分母与成功率口径按 025 处理，本条目不定义统计方法。
- 等级高不代表漏洞影响大；等级只描述结果可再现的程度。
- 无子条目。
