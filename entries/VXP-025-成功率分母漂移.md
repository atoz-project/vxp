## 定义

把换过基数的条件成功率误认为同一分母下的总体成功率。一次统计、跨批次汇总或跨阶段引用中，分母的定义发生更换，分子与分母不再指向同一批纳入观察的单元。逐次记录保持完整，失效发生在比值的基数被替换。事后删除失败样本归 VXP-027。把相关尝试当作独立重复归 VXP-026。

成功率有两类估计量，必须择一。二值成功率的分母固定为观察起点投入的单元总数，未完成单元按未成功计。时间到成功或生存函数 S(t) 的分母是各事件时刻的风险集，即当时仍在观察的单元集合。时间到事件估计量只能给出曲线或分位数，不能压缩成一个标量比值。两类分母混用时，同一个数值既不对应固定样本比例，也不对应风险集比例。

## 示例

某批 40 次尝试中，12 次未进入第二阶段。报告只取进入第二阶段的 28 次，称“成功率 90%”。原始记录显示 40 次中成功 25 次。错误结论是总体成功率 90%；证据支持总体 25/40，另有一个条件指标 25/28。

## 识别方法

- 要求同时给出分子、分母和分母定义标识，并从逐次记录独立重算比值。
- 按单元标识做集合检验：是否存在成功但不在分母中的单元，或分母中无对应记录的单元。
- 检查分母单元类型是否与结论粒度一致：单元是尝试、独立世代还是目标实例。
- 检查估计量类型：报告单一比值时，确认分母是固定单元数；使用风险集时，要求曲线或分位数。
- 检查版本、配置、阶段是否合并，合并后是否分层。
- 最小证伪：用同一份原始记录重算；无法复现公布的分母即判为漂移。

## 预防与验收要求

- 每个成功率指标必须绑定一份分母定义，写明单元类型、观察起点、纳入与排除条件、时间窗。
- 分子与分母必须来自同一份逐次记录，分子集合必须是分母集合的子集；不得跨数据源拼接。
- 二值成功率与时间到事件估计量不得混用：前者报告固定分母的比值，后者报告风险集曲线与分位数。
- 汇总前必须按版本、配置、阶段分层；各层定义一致才允许合并，否则分层报告。
- 报告必须写明“总体”或“条件”；条件成功率同时给出条件事件与条件分母。
- 分母定义变更必须视为新指标，保留变更前后的两套数值。具体次数、比例与时间窗由项目验收方案定义。

## 验收证据与量化字段

- 逐次记录：单元标识、阶段、结果、时间戳。
- 分母定义说明：单元类型、观察起点、纳入与排除条件。
- 重算输出：分子、分母、比值。
- 分层表与合并规则。

| 字段 | 含义 | 单位/取值 |
|---|---|---|
| `denominator_definition_id` | 分母定义唯一标识，指向书面定义 | 字符串 |
| `denominator_unit` | 分母计数的单元类型 | 枚举：attempt / generation / target_instance |
| `units_started` | 观察起点投入的单元总数，二值估计量的分母 | 个 |
| `units_at_risk_t` | 某事件时刻仍在观察的单元数，时间到事件估计量的分母 | 个 |
| `numerator_units` | 属于分母集合且判为成功的单元数 | 个 |
| `stage_gate` | 计入分母前必须到达的阶段；无门槛为空 | 阶段名 |
| `rate_binary` | `numerator_units / units_started`，仅二值估计量使用 | 比值 |
| `strata_count` | 合并前参与汇总的层数 | 个 |
| `definition_change_count` | 统计周期内分母定义变更次数 | 次 |

## 边界与关联

- 条件成功率本身合法，只要写明条件事件与条件分母。
- 删失属于正确处理：未失效单元留在风险集中直到观察结束。
- 样本独立性与顺序效应分别由 VXP-026、VXP-030 判断。
