## 定义

把“有报告和结论”误认为“未参与者可以重建执行过程”。判据是盲重建：不给口头补充，读者能否复述谁在何时对什么目标做了什么、得到什么结果。完全没有证据属于证据缺失，不在本条目范围。

## 示例

报告写“利用成功”，附一张汇总表，没有命令、退出码、目标标识和尝试编号。报告把结论写成“记录齐全”。证据实际支持“有一个结论摘要”，无法定位到任何一次运行。

## 识别方法

- 做盲重建：未参与者在无口头补充下能否复述执行序列与结论。
- 关键事件是否具备事件类型、时间、地点、来源、结果、主体六类属性。
- 每次尝试是否有唯一 ID、起止时间与退出码。
- 时间是否为 UTC 或带偏移，是否记录时钟来源。
- 记录能否通过制品哈希或尝试 ID 绑定到具体运行。
- 声称时间窗口内是否有轮转、截断或重启造成的中断。

## 预防与验收要求

- 保留原始 stdout、stderr、退出码、命令行及参数、每尝试唯一 ID 和执行起止时间。命令行中的秘密值按 VXP-044 在采集时脱敏，以占位符保留参数结构、参数名与退出状态。
- 记录目标标识、制品版本或哈希、环境指纹与操作者身份。
- 时间统一为 UTC 或带明确偏移的格式，并记录同步来源。
- 原始记录与派生分析分开存放；成功与失败尝试同流保存，不得删除失败记录。
- 存储具备追加写、只读或防篡改能力，保留到验收与争议处理期结束。
- 因敏感信息删减时，保留字段结构、删减位置与原因。

## 验收证据与量化字段

最小证据：

- 运行清单：操作者、UTC 起止时间、环境指纹、制品哈希、脱敏后的命令结构、退出码、目标标识。
- 带每尝试 ID 的原始日志，含成功、失败、异常与重试。
- 目标侧记录或独立观测，能与运行清单中的同一尝试对应。
- 时钟来源与偏差记录。
- 存储完整性凭据。

| 字段 | 含义 | 单位/取值 |
|---|---|---|
| `blind_reconstructable` | 未参与者在无口头补充下能否重建执行序列与结论 | `yes` / `partial` / `no` |
| `event_field_coverage` | 关键事件六类属性（事件类型、时间、地点、来源、结果、主体）覆盖比例 | 比例 |
| `run_manifest_field_coverage` | 运行清单必填字段（脱敏命令、退出码、尝试 ID、制品标识、环境指纹、操作者）覆盖比例 | 比例 |
| `attempts_with_raw_record_ratio` | 有原始记录支撑的尝试数占声称尝试数比例 | 比例 |
| `clock_skew_ms` | 参与主机相对统一时间源的最大偏差 | 毫秒 |
| `log_retention_days` | 原始记录实际保留时长 | 天 |

## 边界与关联

- 某些目标不允许详细日志，此时补充外部观测并记录限制。为隐私或秘密做最小化删减合理，但不得删除事件类型、时间、来源、结果、主体等决策字段。
- 不要求保存全量网络抓包；结论依赖的事件必须有可核对的原始记录。
- 记录完整不等于记录真实；本条不检测伪造，伪造需要签名、监管链或独立来源交叉验证。
- 本条目不判断来源是否独立（VXP-038），也不判断终局是否被观测（VXP-043）。

子条目：

- VXP-040.001 记录中的标识未绑定具体目标与制品：检查记录能否对应到唯一实例与制品哈希。
- VXP-040.002 成功记录被当作逐次尝试记录：检查每次尝试的编号与失败样本是否保留。
- VXP-040.003 时间戳未绑定时间基准：检查时间基准与跨源事件顺序是否可判定。

## 参考来源

1. NIST，SP 800-53 Rev. 5《Security and Privacy Controls for Information Systems and Organizations》，https://csrc.nist.gov/pubs/sp/800/53/r5/final，查询日期 2026-11-20。AU-3 要求审计记录含事件类型、时间、地点、来源、结果与相关主体；AU-8 要求时间戳使用 UTC 或带偏移时间；AU-11 要求按保留策略保存审计记录。支持字段、时间与保留要求。
2. NIST，SP 800-92《Guide to Computer Security Log Management》，https://csrc.nist.gov/pubs/sp/800/92/final，查询日期 2026-11-20。第 2.3.1 节指出主机时钟不准确会使多源日志分析困难；第 3.2 节建议使用时间同步技术使日志源时钟一致。支持统一时间基准与偏差记录要求。
3. NIST，SP 800-115《Technical Guide to Information Security Testing and Assessment》，https://csrc.nist.gov/pubs/sp/800/115/final，查询日期 2026-11-20。第 7.4.1 节建议保留活动日志，至少含日期时间、评估者、评估系统标识、目标系统标识、工具、命令与备注。支持最小运行记录字段。
