## 定义

把利用程序自己的输出、返回值或推断误认为最终效果已经发生，缺少利用路径之外的观测点。

最终效果指合同要求且可观察的终局：命令执行、文件读写、权限变化、持久化、服务中断。观测独立性回答“谁确认效果”，独立复跑（VXP-038）回答“谁执行过程”，两者不可互换；利用链完整性（VXP-017）与进程内外效果之分（VXP-020）也不因本条目通过而成立。

## 示例

某 PoC 打印 `uid=0(root)` 并以 0 退出，报告据此声称提权成功。该行文本由 PoC 自行格式化，目标侧没有对应进程记录，没有相关文件属性变化，也没有审计日志。错误结论：权限提升已实现。证据支持的结论：PoC 输出了预期字符串，目标状态未观测。

## 识别方法

- 要求执行前写清成功谓词：观察对象、期望值、通道、观察者、时点。
- 追溯每条效果证据的生产者：文本、状态码或截图由谁生成，能否在不接触目标时复现。
- 检查观测点与利用路径的信任边界：数据是否由被利用的进程、主机或账号产生和控制。
- 检查运行前基线，以及运行后对同一谓词的对照测量。
- 对持久化、延迟或破坏性效果，检查会话结束后或恢复后的再次观察。

## 预防与验收要求

- 每条终局主张在执行前定义成功谓词与观测计划，不得事后补写。
- 观测应尽量置于利用路径之外。只用带内输出时，须说明该通道为何不可被利用方影响。
- 优先采用目标侧审计日志并实时转发至独立收集器，其次为独立管理接口或第三方探针。
- 必须采集运行前基线，并以独立于利用路径的方法确认同一效果。
- 必须记录阴性对照或等效排除检查。
- 可接受的观测通道与复验时限由项目规定。

## 验收证据与量化字段

最小证据：成功谓词与观测计划；独立观测记录；运行前后基线与差异；阴性对照结果或替代排除说明；观察者身份与采集时间。

| 字段 | 含义 | 单位/取值 |
|---|---|---|
| `observation_independence` | 观测通道相对利用路径的独立程度 | `out_of_band` / `target_audit` / `in_band` / `self_reported` |
| `effect_predicate_defined` | 执行前是否定义可观测的成功谓词 | `yes` / `partial` / `no` |
| `baseline_captured` | 是否采集运行前基线 | `yes` / `no` |
| `negative_control_run` | 是否执行阴性对照或等效排除检查 | `yes` / `partial` / `no` |
| `post_session_recheck` | 会话结束后是否再次确认效果 | `yes` / `no` / `not_applicable` |
| `effect_match` | 实测结果与预定义谓词的匹配程度 | `match` / `partial` / `mismatch` / `unobserved` |

## 边界与关联

- 带内输出在通道经过认证、且利用方无法影响时可作辅助证据，仍应补充目标侧记录。
- 内核崩溃、设备重启只能由外部可用性探测观察时，只要探测点独立、基线明确，仍属有效观测。
- 未观测到效果标为“未验证”，不得直接判定成功或失败。
- 独立观测只证明该效果发生过，不证明可重复、不证明权限边界（VXP-021），也不给出成功率。
- 观测记录粒度不足按 VXP-040 处理；证据不可定位或不可读取按 VXP-039 处理。

## 参考来源

1. NIST，SP 800-115《Technical Guide to Information Security Testing and Assessment》，https://csrc.nist.gov/pubs/sp/800/115/final，查询日期 2026-11-20。第 5 节指出漏洞验证应证明漏洞存在并展示利用时的安全暴露。支撑“展示并观测实际暴露”的要求。
2. NIST，SP 800-53A Rev. 5《Assessing Security and Privacy Controls in Information Systems and Organizations》，https://csrc.nist.gov/pubs/sp/800/53/a/r5/final，查询日期 2026-11-20。第 2.4.2 节把测试定义为在指定条件下运行对象并比较实际状态与期望行为；第 3.3 节要求描述两者差异。支撑预定义谓词与前后对照要求。
3. NIST，SP 800-86《Guide to Integrating Forensic Techniques into Incident Response》，https://csrc.nist.gov/pubs/sp/800/86/final，查询日期 2026-11-20。第 3 章强调记录采集步骤、维护监管链并用摘要校验完整性，使他人可以重复过程。支撑观测记录可追溯、可复核的要求。
